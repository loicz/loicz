## 🏆 Sobr'IA — DINUM × 42 Hackathon · 2026

**The right model for each question — guided by user feedback.**

Part of the award-winning team behind **Sobr'IA**, an adaptive
LLM routing prototype developed for **Conversations**, an open-source
AI assistant designed for integration into **La Suite numérique**.

**La Suite numérique** is the French government's open-source digital
workspace, developed by **DINUM** for public-sector teams. It brings
together tools for collaborative document editing, video conferencing,
messaging, and file sharing, with a focus on **data security and digital
sovereignty**.

Sobr'IA routes each message to a **fast, balanced, or reasoning model**
based on its complexity and capability requirements. Built-in **blind
A/B comparisons** collect real user preferences, helping administrators
select better-suited models within each tier.

With transparent routing decisions, Langfuse monitoring, and EcoLogits
carbon-footprint estimates, the project aims to balance **answer quality,
response time, and resource efficiency**.
